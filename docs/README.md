# Documentation

These pages are also the [docs site](https://seven-leven.github.io/bird_dash/docs/), in the
gallery's design ([`.vitepress/`](.vitepress/config.ts), `npm run docs:dev`). Write for GitHub
first: the site rewrites links to source files into GitHub links, fails the build on a dead link,
and uses GitHub's heading anchors. A section between `<!-- live: … -->` and `<!-- /live -->` shows
its text on GitHub and the named component on the site (the manifesto's colour ramps and icons).

Reference pages describe how the project is today and are kept true as the code changes. Plans
describe work that has not happened yet; each one is deleted (or folded into a reference page) once
it is done.

## Assets

[`assets/`](assets/) holds generated images: the design guide, the icon sheet, the logo sheet, the
logo files and the README's row of the newest drawings. Do not edit them by hand; `npm run design`
redraws them from the code
([`script/design/draw_design_guide.ts`](../script/design/draw_design_guide.ts)), and a contract test
fails when they are out of date.

## Adding a page

- Describes how something works now → top level, and add it to the table above and to the
  [README](../README.md#documentation).
- Describes work to do → `plans/`, with its status in the first lines. Delete it once the work is
  done: the [CHANGELOG](../CHANGELOG.md) records what changed, and git keeps the plan.
- An image → `assets/`, preferably generated by a script so it cannot drift.
